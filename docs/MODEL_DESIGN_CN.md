# 模型设计

所有模型为合成实验研究实现。

| 模型 | 输入 | 输出 | 目的 |
|---|---|---|---|
| Linear / Random Forest | 宏观参数 | 刚度 | 可解释与非线性参数基线 |
| PyTorch MLP | 宏观参数 | 刚度 | 参数深度学习基线 |
| GCN | 节点、连接、正边权 | 刚度 | 图卷积基线 |
| MeshGraphNet-style | 节点与边属性 | 刚度 | 编码、边节点更新、解码 |
| Multi-task | 同上 | 刚度、竖向位移 | 共享图表示 |
| Multi-task + Physics | 同上 | 同上 | 输出之间的扭转关系 |

图模型池化拼接节点均值与最大值。处理器对边更新求目标节点均值，再进行节点更新。
每步保留残差与 LayerNorm。模型输出标准化对数刚度，解码后严格为正；位移
乘训练 RMS 尺度并通过掩码强制约束节点为零。

监督训练采用标准化对数刚度 MSE 和按图平均的位移 MSE。物理损失比较预测刚度
与 `T/theta_pred`，以训练参考刚度缩放。为防止零转角导致发散，反算刚度最多为
参考值的 20 倍，负转角另罚。预热阶段暂不启用物理项，最佳模型在物理阶段后
才允许选取，但选择指标统一为验证集监督误差。

该约束不能保证内部位移满足平衡。实现是简化 MeshGraphNet 风格网络，不宣称
复现原论文全部设置。默认隐藏维度 128、处理步数 6；执行演示为 32、3。

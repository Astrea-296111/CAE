## 真实结果与限制

物理多任务模型的 ID R² 为 0.9645，MAPE 为 4.93%；厚度 OOD R² 为 0.6478，
MAPE 为 11.16%。千个候选 Top-10 召回率为 0.6。与普通多任务相比，本次物理项
略改善刚度指标，但 ID 位移 RMSE 与扭转一致性残差均未改善。

100 个结构的中位时间为合成求解 0.0604 秒、推理 0.0737 秒，另需构图 0.0397 秒。
这是小型教学求解器与 CPU 推理的比较，模型没有在这个基准上加速，不涉及 OptiStruct。

# 项目面试指南

所有项目结果来自合成数据。将本项目称为个人复现或研究型项目，不称为某车型工业落地结果。

## 一分钟介绍

我从车身 CAE 工作中反复更新结构并重新求解的痛点出发，独立复现了一个基于图神经
网络的结构代理模型。项目全部使用合成格架和稀疏弹性网络生成标签，比较参数基线、
GCN 与 MeshGraphNet 风格模型，同时预测整体扭转刚度和节点位移，并加入力矩与
转角的一致性约束。最后用候选 Top-K 召回率评估筛选价值，保留真实 CAE 接口。
它证明的是技术流程可执行，工业效果仍需要合法真实数据和高保真验证。

## 三分钟介绍

工程动机是减少早期大量设计方案逐一求解的成本。我先生成两类有空间连接的结构，
把材料、厚度、约束和载荷放入节点，把长度、方向和弹性代理放入边。标签来自一个
标量弹性网络的稀疏求解，端部相反载荷形成力矩，刚度由力矩除以转角得到。
这不是 OptiStruct，也不是完整车身有限元。

模型方面，我先建立对数刚度的线性、随机森林和 MLP 基线，再比较 GCN 和带边更新
的 MeshGraphNet 风格网络。多任务版本共享编码器，输出刚度和竖向位移；物理项要求
图级刚度与位移反算刚度一致。所有统计归一化只在训练集拟合，检查点按验证集选取。
评估区分 ID 与厚度 OOD，并计算候选前五、前十、前二十召回率。

实际运行的是小规模 CPU 合成实验。多任务物理模型的 ID R² 约 0.965，但这个数字
不是工业成果；千个候选中的 Top-10 召回只有 0.6，说明较高回归精度仍可能漏掉优秀
方案。小型合成求解器比模型推理快，不能用这里的计时宣称工业加速。后续重点是
多种子评估、信息对齐基线、真实数据解析和大图层次建模。

## 五分钟介绍

在三分钟介绍上展开三个工程判断。第一，图模型是否必要需要比较强基线。参数模型
没有观察具体斜撑实现，因此当前比较包含输入信息量差异；下一步应给基线补充拓扑
统计，判断收益来源。第二，物理一致性只关联端部转角与整体刚度，并不保证内部位移
满足平衡；它有转角下界和预热策略，仍需独立验证局部场误差。第三，模型应该进入
“预测筛选、少量高保真验证、反馈训练”的闭环，不负责替代最终工程判断。

说明实际工程化内容：配置控制数据与网络规模，记录来源与单位，保存训练统计和
数据摘要，使用抽象求解器隔离外部软件。测试检查平衡、边界、图批处理、梯度和
检查点恢复。对于真实百万节点车身，应按零件或区域建立层次图，保留关键连接与
载荷路径，同时评估网格密度变化。真实数据必须留在合法授权环境中，公开仓库
只保留合成示例。结束时给出自己最想继续研究的一个问题，例如平衡残差辅助训练。

## 面试问题与推荐回答

1. **数据从哪里来？** 全部由本项目规则生成，不包含真实企业模型。标签由标量稀疏弹性网络求解，结果只适用于这个合成任务。
2. **为什么不用 XGBoost？** 先用随机森林减少依赖，并保留参数基线。是否换 XGBoost 应按验证效果和维护成本判断，不能预先假设 GNN 必须更好。
3. **为什么选择 GNN？** 结构连接与节点属性直接影响响应，图表示能观察具体拓扑实现。它也支持节点输出，但不自动保证物理正确。
4. **图节点是什么？** 合成网络的空间节点，带一个竖向自由度。真实迁移时应区分有限元节点、零件节点及粗化节点。
5. **边是什么？** 已知结构连接的双向表示，包含相对坐标、长度、方向和输入可计算的连接刚度代理。
6. **为什么不是随机图？** 通过轨道、截面和斜撑生成空间网络，使位置、约束与连接具有结构意义。
7. **为什么 MeshGraphNet？** 编码、边节点更新、解码容易表达局部几何与材料交互。这里是风格复现，没有声称复现原论文的全部协议。
8. **消息传递如何工作？** 每条边根据两端节点和边表示更新，再聚合到目标节点，节点结合聚合消息更新自身表示。
9. **处理步数是不是求解迭代次数？** 不是。它是学习的表示更新步数，不等于有限元方程残差收敛迭代。
10. **为什么保留残差和 LayerNorm？** 帮助多步更新的梯度与尺度稳定；效果仍需消融，不能视为物理保证。
11. **为什么多任务？** 用局部场监督补充整体性能监督，但两任务可能冲突，所以分别报告刚度和位移误差。
12. **为什么只预测竖向位移？** 与当前单自由度合成求解一致。预测三轴位移需要重新定义求解器和标签，而不是多加两个输出。
13. **物理损失怎么构建？** 从预测位移算端部转角，再以已知力矩反算刚度，与图级刚度比较；以训练参考尺度缩放。
14. **转角接近零怎么办？** 使用参考尺度决定的下界和负转角惩罚，先监督预热。裁剪会削弱部分梯度，是公开的数值折中。
15. **能否保证满足全部物理规律？** 不能。整体关系一致仍可能有错误内部场，当前没有逐节点平衡或能量残差约束。
16. **边刚度代理是否泄漏？** 由设计和连接输入计算，推理前可得，不由标签反推。但它让任务更贴近已知合成规律，应披露这个信息条件。
17. **如何避免数据泄漏？** 按完整设计划分，训练集拟合所有统计，验证集选检查点，测试集不调参；真实数据还需按结构家族划分。
18. **如何做 OOD？** 训练厚度 0.8 至 1.2，OOD 为 1.25 至 1.4，其他因素保持同类抽样；这只考察一种外推方向。
19. **为什么随机森林 OOD 可能更差？** 树模型通常受训练标签范围限制，难以对连续幂函数趋势外推；神经网络也不保证外推正确。
20. **为什么预测对数刚度？** 刚度为正且跨度较大，对数便于学习相对尺度；最终指标仍在原单位中计算。
21. **为什么看 Top-K Recall？** 实际筛选关心能否把真正优秀的设计留给后续求解，这与整体平均误差不同。
22. **Top-K 的真值如何得到？** 本演示额外求解整个候选池用于审计。真实环境需要离线完整标签池或额外验证预算。
23. **千个候选为什么仍有漏选？** 高相关排序不保证集合完全重合，前沿设计接近时很小误差也可能改变名次。可以增加性能容差召回和最优方案损失。
24. **代理是否比求解器更快？** 当前小型合成求解更快，演示不证明工业加速。真实收益必须计入高保真模型和完整流程成本。
25. **换真实车身模型怎么办？** 先建立授权解析器，统一单位、节点 ID、单元属性和工况，再重新设计图特征、标签与数据划分。
26. **百万节点怎么办？** 考虑零件图、网格粗化、分块与层次传播，同时保留边界和关键连接；需要显存与误差的联合评估。
27. **如何做图粗化？** 依据几何、零件和连接语义聚类，保留载荷路径并定义细粗映射，验证粗化后的响应误差。
28. **网格变化如何处理？** 图模型可以处理可变节点数，但网格密度改变会影响特征和聚合，仍需跨密度实验与适当归一化。
29. **如何接入 OptiStruct？** 实现合法输入导出、受控运行、状态检查和结果解析，返回统一响应结构；当前接口明确未实现。
30. **如何保证推荐可靠？** 做覆盖范围检查、误差校准、物理检查和独立 CAE 验证。最终工程评审仍负责决策。
31. **模型预测错了怎么办？** 回退到求解器，记录失败分布和原因，加入后续合法训练数据；不把未验证方案直接用于发布。
32. **如何设计主动学习？** 不同种子集成给候选方差，优先查询高方差样本，固定测试集后重训，并与随机查询比较。
33. **集成方差是否是真实误差？** 不是，只是获取信号；模型可能一致地错，需要校准和独立分布外检查。
34. **为什么不能完全替代 FEM？** 新工况、罕见失效和分布变化可能超出训练范围；代理也没有完整求解器的物理定义和验证依据。
35. **如何衡量实际业务价值？** 在相同求解预算下比较最好已验证方案、可行率、开发时间与人工检查成本，不能只看 R²。
36. **项目最大的不足是什么？** 合成小图与真实壳梁模型存在很大差距，而且当前只有单种子轻量实验，性能结论需要更多证据。
37. **最值得继续做什么？** 首先补充信息对齐的强基线与多种子实验，再研究平衡残差、多尺度图和真实授权数据迁移。
38. **简历怎样写？** 明确个人研究复现、合成数据和真实运行范围；把 CAE 工作经验作为动机，不能将这里的结果描述为公司工业成绩。

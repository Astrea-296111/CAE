# 实验设计

所有数字必须来自当前执行产生的合成数据结果。`experiments/results/metrics.json`
是指标来源，`comparison.csv` 是便于比较的展开表。完整训练输出保存在 `outputs/demo`。

1. 固定数据生成种子与四个划分，先执行生成和完整性测试。
2. 用参数线性、随机森林、MLP 建立基线；同一数据上训练 GCN 与 MeshGraphNet。
3. 对比刚度单任务、位移多任务以及物理辅助多任务。
4. 报告 ID 和厚度 OOD 的 MAE、RMSE、MAPE、R²、Top-5/10/20 Recall。
5. 对 1000 个新候选先预测再验证 Top-10；全池求解仅用于演示审计。
6. 预热后重复 5 次比较 100 个结构上的合成求解和推理，同时记录构图成本。

当前演示预算是 30 轮上限、批大小 12、32 维、3 步、CPU、单种子。
早停按验证监督误差，测试与 OOD 不参与检查点选择。物理模型在预热十轮后启用
0.01 权重。不同输出任务的验证目标有所不同，不能将数值直接跨任务比较。

建议追加但不伪装为已执行的研究包括：5 个模型种子、多个数据种子、信息对齐的
拓扑统计基线、网格密度变化、几何 OOD、物理权重敏感性、消息步数敏感性、
含质量约束的候选筛选，以及主动学习与随机采样在同标注预算下的比较。

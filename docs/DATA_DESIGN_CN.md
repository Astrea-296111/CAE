# 数据设计

本项目所有数据均为合成数据，不含真实企业或车型信息。

| 项目 | 约定 |
|---|---|
| 节点 | 规则空间格架，默认 128 个，仅有竖向位移自由度 |
| 连接 | 纵向轨道、截面连接及概率斜撑，转为成对有向边 |
| 节点特征 | 18 维，定义见 `NODE_FEATURES` |
| 边特征 | 8 维，定义见 `EDGE_FEATURES` |
| 设计参数 | 12 维，顺序见 `DESIGN_KEYS` |
| 标签 | 图级刚度与节点级竖向位移 |
| 单位 | m、N、Pa、mm，刚度 N*m/rad |
| ID 厚度 | [0.8, 1.2] mm |
| OOD 厚度 | [1.25, 1.4] mm |

公开示例为 `data/synthetic/example_design.json`。执行生成入口后得到含四种划分的
数据文件，每种划分为 PyG `Data` 列表。默认完整样本数为 300/50/50/50；
轻量演示为 120/30/30/30。随机流、拓扑规则与种子构成合成样本身份。

密度保留为输入字段，但不参与静力求解。载荷决定响应幅值，不改变线性网络刚度。
斜撑概率控制随机拓扑，宏观设计参数无法完整描述该次实现。边刚度代理由结构输入
计算，不能通过真实刚度或位移反算。构造候选图时不求解、不携带标签。

归一化只拟合训练集。节点和边使用均值及标准差，对数刚度使用训练统计，位移使用
训练均方根。边权在 GCN 中保持正值，不能把标准化后的负数作为弹性边权。
各划分以整个设计为单位。真实数据迁移应按设计家族划分，另查重复、缺失、单位和
网格版本，避免仅按节点随机划分。
